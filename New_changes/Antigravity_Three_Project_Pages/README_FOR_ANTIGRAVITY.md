# Antigravity — Three Project Pages Package

## Objective

Build and fully format three individual project pages:

1. **AI Startup — Strategic Market Consulting**
2. **Digify Active — B2B Growth & Marketing Analytics**
3. **Oblicuo Hi-Fi Bar — Customer Research & Growth Strategy**

Use the copy and structure in this package as the source of truth. Do not invent additional outcomes, metrics, clients, tools, responsibilities, or project ownership.

## Required routes

- `/projects/ai-startup-strategy`
- `/projects/digify-active`
- `/projects/oblicuo-customer-strategy`

## Shared page structure

Every project page must use the same reusable page template:

1. Back to Projects
2. Hero
3. Project at a Glance
4. Business Challenge
5. Approach
6. Key Findings / Analysis
7. Recommendation or Solution
8. My Contribution
9. Outcome
10. Visual Evidence
11. Previous / Next Project navigation

The template must be reusable. Do not build three separate unrelated page systems.

## Shared visual rules

- Reuse the website’s existing colours, typography, spacing, shadows, radii, and container widths.
- Do not introduce a new project-page design system.
- Use a maximum content width consistent with the rest of the site.
- Use a clear editorial rhythm: text block → visual → text block.
- Avoid long uninterrupted walls of text.
- Keep body copy readable at 100% browser zoom.
- Use responsive images with no distortion.
- Keep image captions concise.
- Use the existing blue accent only for emphasis, tags, links, and selected UI states.
- Do not make all sections look like identical white cards.
- Use cards only where the information benefits from comparison or scanning.
- Project navigation must work on desktop, tablet, and mobile.

## Copy rules

- Use the exact public project names supplied in this package.
- Do not expose the confidential AI startup name anywhere on the website.
- Do not imply that recommendations were implemented unless the copy explicitly says so.
- Do not convert proposed KPIs into achieved commercial results.
- Preserve the distinction between team work and Elena’s personal contribution.
- Keep project type visible near the title.
- Keep all website copy in English.
