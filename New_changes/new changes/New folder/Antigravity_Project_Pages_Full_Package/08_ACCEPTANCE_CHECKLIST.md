# Acceptance Checklist

## Overall storytelling
- [ ] Every page reads like a visual case study, not a report
- [ ] Every page follows the logic: problem → analysis → insight → recommendation → contribution → outcome
- [ ] Long repeated white-card sections are removed

## Shared structure
- [ ] Hero
- [ ] Compact metadata strip
- [ ] Business Challenge
- [ ] Key analytical visual near the top
- [ ] Research / Analysis
- [ ] Key Insights
- [ ] Main framework / journey / funnel
- [ ] Strategic Recommendation
- [ ] My Contribution
- [ ] Outcome
- [ ] GitHub evidence link
- [ ] Previous / Next navigation

## Visual quality
- [ ] Existing project visuals are reused where appropriate
- [ ] New visuals are created where required
- [ ] New visuals follow the site design system
- [ ] No distorted images
- [ ] No invented metrics or results
- [ ] Mobile readability is preserved

## AI Startup confidentiality
- [ ] Confidential startup name is not visible anywhere on the website
- [ ] Old startup name is not present in visible filenames, alt text, captions, metadata, or structured data

## Responsive QA
- [ ] 1920×1080 at 100% zoom
- [ ] 1536×864 at 100% zoom
- [ ] 1440×900 at 100% zoom
- [ ] tablet
- [ ] mobile

## Code quality
- [ ] One reusable page template is used
- [ ] Existing design tokens are reused
- [ ] No CSS zoom or transform scaling
- [ ] No duplicated page-specific component systems
- [ ] No unnecessary global CSS rules
- [ ] No console errors or warnings
