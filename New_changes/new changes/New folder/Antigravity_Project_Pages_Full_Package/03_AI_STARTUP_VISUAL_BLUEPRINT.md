# AI Startup — Strategic Market Consulting

## Public title
**AI Startup — Strategic Market Consulting**

## Route
`/projects/ai-startup-strategy`

## Confidentiality rule
Do not expose the confidential startup name anywhere on the website.

## Page character
This page should feel **strategic, structured, and decision-framework-led**.

## Recommended section structure and visuals

### 1. Hero
Use a neutral strategic visual (cropped or anonymised if needed).

Hero tags:
- Market Research
- Competitive Benchmarking
- Market Prioritisation
- Strategic Positioning
- Go-to-Market Planning
- Executive Communication

### 2. Compact metadata strip
Fields:
- Project Type: Academic consulting project
- Methods: Market research, benchmarking, prioritisation
- Focus: Vertical selection and differentiation
- Deliverable: Strategic recommendation + roadmap

### 3. Business Challenge
Short context paragraph + the highlighted core question:

**Which market vertical should the company prioritise to achieve stronger differentiation and scalable growth?**

### 4. Visual A — Business challenge / decision context
Use an existing challenge or overview visual.

### 5. Research & Analysis
Do not use three identical white cards. Use a split layout.

Left or top: short text on how the team compared possible applications.
Right or bottom: framework visual.

### 6. Visual B — Prioritisation framework
This must be one of the most important visuals on the page.

Use a clean matrix or framework showing the comparison logic.

Required criteria:
1. Market attractiveness
2. Demand potential
3. Competitive intensity
4. Regulatory environment
5. Adoption barriers
6. Implementation feasibility
7. Scalability and defensibility

### 7. Key Insights / Recommendation Logic
Create a highlighted analytical section showing the logic that led to the recommendation.

Recommended format:
- 5 numbered logic steps;
- one short sentence for each.

Required recommendation logic:
1. defined customer problem;
2. relevant role for the technology;
3. measurable business value;
4. realistic adoption and implementation requirements;
5. defensible source of differentiation.

### 8. Strategic Recommendation
Lead statement:

**Shift from broad horizontal competition to focused vertical specialisation.**

Supporting principles:
- prioritise a clearer use case;
- align with demand and implementation reality;
- reduce go-to-market ambiguity;
- strengthen differentiation;
- support scalable market entry.

### 9. Visual C — Go-to-Market Roadmap
Use a 4-step horizontal roadmap on desktop and vertical roadmap on mobile.

Stages:
1. Validation
2. Pilot Design
3. Focused Market Entry
4. Expansion

### 10. My Contribution
Use a distinct contribution block.

Recommended headings:
- Contributed To
- Personally Handled

Use the approved contribution copy.

### 11. Outcome
Keep this concise and accurate.

### 12. Final evidence / GitHub / Previous-Next
Link to GitHub using the existing project link, but keep the website wording neutral.
