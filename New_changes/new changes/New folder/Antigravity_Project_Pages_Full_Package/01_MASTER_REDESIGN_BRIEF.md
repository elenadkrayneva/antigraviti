# Master Redesign Brief — All Three Project Pages

## Objective

Redesign all three project pages so they no longer look like text-heavy reports. Each page should feel like a visual case study with stronger storytelling, more hierarchy, and more use of diagrams, screenshots, and framework visuals.

## Shared rules for all pages

### 1. Replace the current “report” feel
Do not solve this by adding more white cards. Do not keep repeating the same block pattern section after section.

### 2. Compact metadata instead of a large “Project at a Glance” box
Replace the oversized 4-column text block with a compact metadata strip. Example structure:

- Project Type
- Methods
- Focus
- Deliverable

Each item should be a short line, not a paragraph.

### 3. Do not repeat the business question twice
Show the core question only in the **Business Challenge** section.

### 4. Alternate text and visuals
Use a rhythm like:

**Text → Visual → Insight → Visual → Recommendation**

Avoid:

**Text → Cards → Text → Cards → Text**

### 5. Use multiple layout types
Across each page, combine:

- full-width hero visual;
- split text/image layouts;
- large highlighted insight blocks;
- framework or matrix visuals;
- numbered insights;
- process flows or roadmaps;
- contribution block;
- outcome summary.

### 6. Keep long text narrow
Body text blocks should not become very wide on desktop. Target readable line lengths and use a maximum text width of roughly 650–700 px.

### 7. Strategic Recommendation must be a high-emphasis section
Each page should have one visually stronger section that clearly states the recommendation.

### 8. My Contribution must be more visible
Use a distinct block, ideally split into:

- Independently Developed / Led
- Contributed To

Only use factually supported ownership.

### 9. Reuse existing page components where possible
Use one reusable project-page template, but do not make all three pages visually identical.

### 10. Respect existing site design system
Reuse the existing palette, typography, spacing, shadows, border radii, and button system.

Do not introduce a new mini design system for project pages.
