# Antigravity — Full Project Pages Package

This package contains everything needed to redesign and fully format the three project pages as visual case studies:

1. **AI Startup — Strategic Market Consulting**
2. **Digify Active — B2B Growth & Marketing Analytics**
3. **Oblicuo Hi-Fi Bar — Customer Research & Growth Strategy**

## What is inside

- full redesign brief for all three pages;
- storytelling and layout rules;
- exact section-by-section visual blueprints;
- reuse map for existing GitHub assets;
- new diagrams and schemes to create;
- wireframe PNGs for each page;
- table of all visuals by section;
- acceptance checklist;
- JSON manifest.

## Core redesign goal

The current project pages feel like formatted reports made of repetitive white cards. Redesign them into editorial visual case studies that guide the user through this logic:

**Business problem → research/analysis → key insight → recommendation → personal contribution → outcome**
