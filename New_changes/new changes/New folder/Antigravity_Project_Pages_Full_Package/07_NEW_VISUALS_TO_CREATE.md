# New Visuals and Schemes to Create

Create only the visuals listed below. Do not invent unsupported numbers.

## AI Startup
1. Compact metadata strip
2. Recommendation logic flow (5-step logic)
3. Clean 4-stage roadmap if the source roadmap is too dense

## Digify Active
1. Compact metadata strip
2. Customer journey diagram
3. Acquisition funnel diagram
4. Search vs Display comparison block
5. Performance-analysis metric strip
6. Optimisation recommendation grid
7. Contribution block visual

## Oblicuo
1. Compact metadata strip
2. Research-in-numbers strip
3. Priority-segment spotlight block (After-Work Neighbor)
4. Customer-journey diagram if a stronger visual is needed
5. Contribution block visual refinement if needed

## Shared style rules for new visuals
- use the existing site palette;
- use existing blue accents for emphasis;
- keep typography consistent with the site;
- do not make every visual a white card;
- use subtle borders, dividers, and background tints from the existing design system;
- ensure mobile readability;
- export visuals so they remain sharp on high-resolution screens.
